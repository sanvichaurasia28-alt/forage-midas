# JPMC Forage – Advanced Software Engineering (Midas Project)

This project simulates tasks from the **J.P. Morgan Chase Forage Advanced Software Engineering Program** using a Spring Boot backend.

---

## 🚀 How to Run

### Clone the project
```bash
git clone https://github.com/your-username/forage-midas.git
cd forage-midas
```

### Run locally (without Docker)
```bash
./mvnw spring-boot:run
```
Then open: **http://localhost:8080**

### Build a jar
```bash
./mvnw clean package
java -jar target/*.jar
```
